# 建议交互

直接运行 `gcommit`，读取当前仓库净变化并调用本机已登录的 Codex。无需在目标项目安装任何依赖。配置、模型、语言、风格、过滤规则及预算与 [dry-run](DRY_RUN.md) 共用。

## 操作

| 操作           | 行为                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 使用此 Commit  | 复核快照，进入默认取消的最终确认；同意后才暂存并提交。                         |
| 修改标题和正文 | 保留当前风格，编辑完整标题；正文每行一条，不写 `-` 前缀，可清空。              |
| 重新生成       | 将上一版建议作为未采用的数据，和原始净变化一起发送；提示模型按事实换一种建议。 |
| 查看 Diff      | 展示 HEAD 到工作树最终版本的脱敏 Diff 变更块及行号、模式变化。                 |
| 取消           | 结束当前流程，不修改仓库。                                                     |

菜单使用方向键和 Enter，默认选中取消。标题 Enter 进入正文；正文支持多行，Tab 切到 `[ submit ]` 后 Enter 保存，Esc 放弃本次编辑并保留原建议；清空正文使用退格键（Clack 多行输入不提供 Ctrl-U 清空）。多行正文中不接受空白条目。

菜单 Esc、Ctrl-D、EOF 或选择取消正常退出；编辑中的 Esc 仅取消本次编辑。Ctrl-C 与 SIGTERM 结束整个会话，退出码分别为 130/143。失败退出 2。输入和输出都必须是支持编辑的 TTY，`TERM=dumb` 在调用模型前拒绝；管道/自动化环境使用 `--dry-run`，不会自动选择建议。

## 内容与状态

- Conventional 格式编辑完整 `type(scope): subject` 标题，scope 可省略；repository 格式直接编辑完整标题。保留 Schema 长度、条数、格式与终端控制字符检查；空标题和控制字符仍拒绝。生成与编辑内容不再因敏感值或 `[REDACTED]` 被拦截，是否采用由用户审核。
- 编辑时正常显示用户在本地键入的文字；结构与格式校验在接受前执行。重新生成时，上一版建议仅在再次发送前脱敏，不改写本地已展示内容。工具不保存编辑草稿或重试历史到项目文件，也不把失败输入放入模型上下文或错误诊断。
- 重新生成会再次使用网络和 Codex 额度；仅携带上一版，不累计所有轮次。上一版也计入 `maxContextBytes`。模型可能仍产生相同建议，工具不伪造差异。
- 模型超时、无效结果或预算超限保留上一版供选择；隔离失败和 Git 状态错误终止。正在调用模型时可 Ctrl-C 取消，不自动重试。
- 每次进入菜单、重新生成、展示 Diff、接受编辑及使用建议时检查 HEAD/index/工作树快照；模型返回后也复核。期间改变使旧建议失效，需要重新运行。
- Diff 复用全文脱敏后、按原始变化确定的 unified 变更块，通常保留前后各三行，只省略块之间及首尾的未变内容。所有修改行均保留；复杂计算超时会保留完整前后文本，并接受相同的输入预算检查。大视图通过终端滚动查看，不启动 pager。
- Diff 行内容使用引号和转义表示，不解释终端控制字符；二进制、符号链接和敏感文件纯删除只展示元数据。秘密可能使不同文本在视觉上相同，不能据此判断没有变化。过滤并不把文件从将来的 Git 提交中排除。

## 当前边界

建议菜单本身不写 Git。Step 6 已接入最终确认、限定范围暂存、提交与 hooks；选择使用后还需一次明确确认。Step 7 已接入单独确认的推送，目标解析与限制见 [推送说明](PUSH.md)。不运行目标项目检查，仓库自有 hooks 仍按配置执行。见 [提交说明](COMMIT.md)。

平台与 Codex 版本继续遵守 [隔离说明](CODEX_ISOLATION.md)；未扩大支持范围。

## 验证

`pnpm check` 覆盖真实临时 Git 仓库和假 Codex 的状态转换、秘密过滤、预算、快照失效、失败恢复，以及 Clack 的真实输入/输出流和监听器清理。实际 CLI 另使用 macOS 伪终端验收编辑、查看 Diff、重新生成、使用、取消和进程信号。独立打包安装后重复终端验收，目标没有 package.json/node_modules。
