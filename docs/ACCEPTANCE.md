# 验收与平台支持

Step 9 将完整终端流程纳入可重复执行的测试。当前支持范围仍是 **macOS arm64 + Codex 0.162.0-alpha.17.2**；跨平台验收尚未完成，不能把模拟平台参数的拒绝测试当作实机验证。

## 执行入口

在 gcommit-cli 仓库安装开发依赖；目标 Git 项目不需要 package.json、node_modules 或任何依赖。

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test:e2e
```

- `pnpm check`：类型、格式、编译及行为测试；使用临时 Git 仓库与 Codex 替身，不调用真实模型；包含模型设置的真实 PTY 测试，需 Python 3。
- `pnpm test:e2e`：16 个真实 PTY 流程和 2 个外层超时清理回归，使用发布入口 `dist/cli.js`、真实 Git 和本地 bare remote，Codex 使用受控子进程替身。需要本机 Python 3（只使用标准库，无 pip 安装）。Python 不是 gcommit 运行依赖；不包含在发布包中。
- 验收从独立临时目录启动，Git/global config/签名/hooks 和 HOME 隔离；支持通过 `GCOMMIT_TEST_CLI` 指向安装包 `dist/cli.js` 的绝对路径，重复验收同一套流程。入口必须是 JavaScript 文件，不能填写 pnpm 的 shell shim。

```bash
GCOMMIT_TEST_CLI=/absolute/path/to/installed/gcommit-cli/dist/cli.js pnpm test:e2e
```

离线 PTY 覆盖：建议默认取消、提交默认取消、推送默认取消、`--no-push`、正常提交推送、多 remote 选择、pre-commit/pre-push 拒绝、推送确认 SIGTERM、远端已更新后的 SIGINT、隐藏推送目标拒绝、URL 脱敏、Diff/重新生成/编辑、过期确认、首次提交、子目录启动。每个流程核对确认前 HEAD/index/remote、最终提交内容、实际远端 refs 和退出码；确认后的全量提交包含部分暂存文件的工作树最终版本、untracked、中文/空白/选项形状路径与二进制文件。检查 stdout/stderr 与模型输入中的合成秘密已过滤；过滤不排除 Git 提交中的文件内容。

## 真实 Codex

以下命令是显式验收，不包含在 `pnpm check` 或 `test:e2e` 中。

```bash
pnpm test:codex:isolation
pnpm test:codex:live
pnpm test:dry-run:live
pnpm test:e2e:live
```

- isolation：真实本机 Codex 连接无认证 loopback 夹具，核实无工具清单、没有自动注入项目上下文、拒绝九类伪造工具调用；不向夹具发送凭据，详见 [隔离说明](CODEX_ISOLATION.md)。
- codex:live：复用既有登录发送固定结构化合成请求，消耗少量额度。
- dry-run:live：合成 Git 仓库经真实模型生成建议，Git 快照不变。
- e2e:live：临时仓库和临时 HOME，只以原 CODEX_HOME（未设置时为原 HOME/.codex）复用既有认证，不复制凭据；只发送合成上下文。真实建议经 PTY 的两次明确确认后提交、推送到本地 bare 接收端，断言消息格式而不硬编码模型文案。消耗少量额度。

这些命令不测试生产远程的 SSH/HTTPS 认证，不联系用户仓库的 remote。live 失败必须保留失败结论，不能替换为 Codex 替身后宣称真实调用通过。临时测试仓库在测试结束后清理，不保留生成提交。
