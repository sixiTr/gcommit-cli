# dry-run 使用与边界

`gcommit -d`（等同 `gcommit --dry-run`）默认请求中文建议：在任意 Git 仓库或子目录读取净变化，过滤内容，调用本机登录的 Codex，校验并展示一个提交建议。目标项目不安装依赖，也不运行项目的测试或构建。

```bash
gcommit -d
gcommit -d --style conventional
gcommit -d --language en
gcommit -d --model <本机支持的模型> --reasoning high --debug
```

默认命令已提供建议菜单及 Step 6 最终确认提交；`--dry-run` 始终不执行 add、commit、push 或 hooks。无净变化时不调用 Codex；非 TTY 可以分析。准备阶段逐文件让出事件循环并检查取消；SIGINT/SIGTERM 会取消调用、清理私有目录，分别退出 130/143；其他失败退出 2。强制 SIGKILL 无法运行清理逻辑。

## 生成进度

默认展示五阶段：读取并复核 Git 变更、过滤并准备上下文、检查 Codex 环境、等待 Codex 生成建议、校验建议与仓库状态。阶段序号表示执行顺序，不代表已完成的时间比例。上下文大小是完整 Prompt 的 UTF-8 字节数，以 KB 展示。

交互提示每秒刷新当前阶段耗时；等待生成超过 30 秒时显示“仍在等待 Codex 返回”，不推断网络或服务异常。Ctrl+C 沿用现有取消与进程清理。非 TTY、窄终端、TERM=dumb 和 --debug 不输出进度动画，仅在阶段切换及等待每十秒输出普通文本；建议正文仍在 stdout，进度位于 stderr。

结束时汇总本地准备、Codex 检查、Codex 生成及校验的耗时。Codex 生成项包含 codex exec 的进程启动、网络等待与服务端生成，不能直接视为纯模型推理时间。成功、失败、取消或无变更均停止刷新，未执行阶段不显示为完成。“重新生成”重新计时，菜单等待、编辑、提交和推送不计入生成耗时。不展示模型思考内容或无依据的完成百分比。

Codex 环境检查通过后，单独显示本次模型和推理档位，例如 `模型：example-model（默认） · 推理档位：low（模型默认）`。显式设置不带默认标记；未显式设置时从本机目录解析，档位无法确认则显示 `auto（由 Codex 决定，具体档位未知）`。提示复用已有目录读取，不额外启动 Codex，也不改变传入模型的参数。预览、交互及重新生成均显示，内容只写 stderr。

## 发送范围

仅发送 HEAD 到工作树最终版本的净变化、最多十条过滤后的历史标题、语言和风格要求。不会发送仓库绝对路径、分支、Git OID/摘要或 staged/unstaged 原始 patch。历史仅供风格参考；模型被告知代码、路径、历史和注释是不可信资料。

终端在调用前逐文件列出“文本”或“仅元数据”，说明是否遮蔽秘密、是否省略未变化内容。二进制、符号链接和敏感文件删除只提供路径、变更类别、大小及模式，不推断其实现。

普通文件的前后内容、原始 patch 及历史会在本地扫描常见凭据；识别到的值在全部待发送文本中遮蔽。规则覆盖普通/带简单类型注解的凭据赋值、YAML 块值、Python 三引号、授权头、常见 API Token、JWT、带密码 URL、PEM 私钥与证书。相同值出现在历史标题或其他文件时也遮蔽。秘密区间在原文上合并后一次替换，保留换行；裁剪范围由原始前后版本确定，不因脱敏结果相同而丢弃变化行。无法确定完整凭据声明边界时停止。原始 patch 作为可能不完整的片段额外扫描，不作为完整语言源文件解析。模型输出再次检查已知秘密及常见凭据，并拒绝控制字符、非法格式、额外字段和过长消息，不打印原始失败响应。

敏感路径包括 `.env` 及其点号/连字符变体（含 `.env.example`）、`.envrc`、`.npmrc`、`.pypirc`、netrc、`.aws/.ssh/.gnupg/.docker/.kube` 目录、secrets/credentials/service-account/auth.json、SSH 私钥以及 key/pem/p12/pfx/jks/keystore/crt/cer/der 后缀。这些文件有新增或修改时，在 Codex 调用前停止；纯删除可以只分析元数据。敏感文件在原始有界采集阶段仍可能因大小超限而停止。

**过滤仅影响 AI 上下文，不是 Git 排除规则。** 常见凭据检测可能误拦模板或非秘密字面值，也无法识别任意个人、业务敏感数据或编码/拆分秘密。不会声称已经自动确认代码可公开。若包含不应发送的信息，请先缩小变更范围。

## 预算

- 原始采集最多 200 个候选路径；单个文件版本 `maxFileBytes` 默认及最高为 10 MiB，总读取量 `maxReadBytes` 默认及最高为 20 MiB。总量包含 staged/unstaged patch、序列化历史、每个文件的 HEAD 和工作树版本，两份版本分别计入；不是只计算工作树文件大小。读取文件内容前按已知大小检查剩余预算，超限停止；小文件按实际大小分配缓冲区。index 和元数据命令单流保留独立的 4 MiB 上限。原始内容不直接落入 Prompt 或诊断日志。
- AI 预算 `maxContextBytes` 默认 1 MiB，可配置为 8 KiB–8 MiB，与本地读取量独立：计入固定任务说明、历史、文件信息以及 JSON 转义后的完整 Prompt UTF-8 字节，不按字符数估算。
- 文本统一发送真实 unified Diff 变更块，通常保留前后各三行上下文。省略变更块之间及首尾未变化的内容，保留全部增删行；每个块包含两侧行号、行数、带前缀的行文本和末尾缺少换行标记。模式变化、空文件增删继续由元数据表达。`full` 表示全部文本已覆盖，`trimmed` 表示省略了未变行，两者都保留全部修改。
- 差异计算在内存执行，不额外写出原始代码。按原文确定修改位置，再从整文件脱敏结果取行，保留仅凭据值变化的事实。单文件高复杂度差异计算设置一秒尝试期限；超时退回完整前后文本，不返回部分变更块。准备阶段在文件之间响应取消。
- 所有文件只发起一次模型生成，不分批、不生成中间摘要。完整 Prompt 超限即停止，不丢弃文件或修改行。单个很大的修改行、新增/删除内容不能靠裁剪解决。Schema 另受适配器 64 KiB 上限，模型响应 16 KiB，CLI 组合后的提交消息最多 4 KiB；`maxContextBytes` 用于限制发送量和资源开销，不是服务端精确 token 总量限制；增大它不会扩大模型本身的上下文窗口，所选模型仍可能拒绝输入。

本地读取失败使用 `GIT_CONTEXT_LIMIT`，文件超限会显示 HEAD/工作树来源、候选文件编号、准确字节数、易读单位、上限与配置项。Git 流输出提前超限时只能报告输出上限和“完整大小未知”。模型 Prompt 超限使用 `ANALYSIS_CONTEXT_LIMIT`，报告裁剪后的实际字节数与 `maxContextBytes`，不会分批或发送部分上下文，错误会区分 CLI 字节预算与模型容量。两类预算都与推理档位无关。超限时尚未完成跨文件秘密扫描，因此隐藏原始路径；候选编号按本轮去重排序后的候选路径从 1 编号，同一文件的两个版本使用相同编号。可结合自己的 `git status` 与文件大小检查，不会为展示路径继续突破预算读取内容。

已有配置中的较低预算不会被升级覆盖；删除旧值即可使用新默认值。

## 建议格式

允许的提交类型：`feat`、`fix`、`update`、`refactor`、`perf`、`style`、`docs`、`test`、`build`、`ci`、`chore`、`revert`。`update` 用于现有功能或内容的常规更新，例如 `update(home): 更新首页展示文案`；明确新增功能或修复错误时，仍优先使用 `feat` 或 `fix`。这些类型可由模型选择，也可在交互菜单中修改标题时使用。

模型只能返回 `format/type/scope/subject/body`。`format=conventional` 使用允许的 type 和可选 scope，CLI 组合标题；`format=repository` 要求 type/scope 为 null，subject 是完整标题。body 是最多八个单行要点，由 CLI 添加项目符号。`message` 完全由 CLI 生成。

默认 `language=zh-CN` 请求中文；显式配置或参数仍可选 `en` 或 `auto`。`language=auto` 参考历史语言，无明确历史时参考代码/文档，否则使用英语。`style=auto` 参考历史风格，无法判断时使用 Conventional Commits。用户指定的格式会本地强制校验；语言和事实准确性仍需人工判断。

生成后重新检查 HEAD、index 和工作树快照；分析期间变化会使建议失效。它检测通常的并发编辑，不是对恶意并发替换的系统级隔离。

## 验证

`pnpm check` 包含过滤、字节预算、响应语义和临时 Git 仓库/假 Codex 子进程测试，不使用真实额度。

`pnpm test:dry-run:live` 会使用真实登录的 Codex 和临时合成仓库，可能访问网络和消耗额度。权限隔离复验见 [Codex 隔离说明](CODEX_ISOLATION.md)。当前只验收 macOS arm64 + Codex 0.162.0-alpha.17.2，其他版本或平台仍被拒绝。
